# Local test fixtures

This directory is for local test media generated or selected by developers. Its contents are ignored by Git except for this README and any reusable scripts placed under `scripts/`.

Do not commit personal videos, exported MP3 files, decoded PCM, `.llc` projects, before/after manifests, or test logs.

For manual audio-extraction acceptance tests, see [`../test-manual/README.md`](../test-manual/README.md).
